# Substantial audit support

Design, Verify Setup and Coordinate now carry a shared guide for requested multi-screen or end-to-end audits. It adds process/check mapping, explicit coverage and evidence, challenges of important findings, separate defects/improvements/decisions, design constraints and bounded recovery. It does not expand routine edits, verification-guide maintenance or read-only code review into a product audit.

The guide is maintained once in `workflows/substantial-audit.md` and packaged locally in the three skills for standalone installation. Retro adds an adaptable decision-focused report template. Existing routing, authorization, target-based platform verification and separate code-review axes remain in force. No new skill, model policy, always-on monitor or product-specific rule is introduced.

These changes generalize observed audit lessons without publishing project records: capture is not inspection; process behavior needs interaction evidence; important claims need checking against applicable rules; proposals preserve accepted visual constraints; retries need current task/output state. Any trial outcome is separate from these intended benefits.
