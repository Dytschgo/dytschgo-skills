# Source and consolidation notes

Astra Design consolidates the author's installed design skills into a new, self-contained instruction set. Its entrypoint and references were written for this collection rather than concatenating the source manuals.

| Reviewed skill | Retained contribution |
| --- | --- |
| web-design | Inspect the existing product first; content truth, complete implementation, and rendered verification |
| interface-design | Task-oriented hierarchy, density, token consistency, and reuse of accessible controls |
| frontend-design | Subject-specific art direction, deliberate typography, and focused visual emphasis |
| triumphoid-anti-slop-frontend, credited locally to Elizabeth Sramek | Visual thesis, independent expression/motion/density decisions, and questioning template defaults |
| Impeccable by Paul Bakaus | Surface-specific priorities, refinement versus redesign, focused review operations, and evidence-based finishing |
| animated-websites | Motion architecture, static fallbacks, bounded media resources, and interruption testing |
| UI/UX Pro Max | Optional searchable design guidance, stack detection, query relevance checks, and data provenance |

The Dylan-specific website skill was reviewed and intentionally excluded. Astra Design contains no personal brand preset.

Removed from the combined workflow: mandatory design-engine downloads, automatic hook setup, unrelated configuration repairs, command menus, universal style bans, fixed aesthetic presets, repeated approval questions, obligatory agent teams, and rigid limits that could leave defects unresolved. Existing user and repository instructions continue to govern scope and authorization.

## Bundled lookup library

`library/ui-ux-pro-max/` contains the locally maintained UI/UX Pro Max search implementation and data snapshot, derived from [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill). It retains its [upstream MIT notice](library/ui-ux-pro-max/LICENSE). Local maintenance includes expanded catalogs, reasoning contracts, and provenance validation; this is not claimed to be an unmodified upstream release.

Only the runtime search modules, integrity validator, and their data dependencies are included. The old skill entrypoint, plugin-specific paths, bytecode caches, and unrelated maintenance/test scaffolding are excluded. No engine executable, font binary, icon artwork, or third-party frontend skill manual is bundled.

The catalog's `data-provenance.json`, `catalog-summary.json`, and font-license metadata remain with the data. These identify recorded sources and verification dates; they do not transfer asset rights or establish current compatibility. Retain the library's notice when redistributing it. Astra's new instructions are covered by the repository license.
